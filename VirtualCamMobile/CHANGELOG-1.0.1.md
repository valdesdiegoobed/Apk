# VirtualCam Mobile 1.0.1

- Mejora de compatibilidad del navegador interno con AforeWeb y otros sitios modernos.
- User-Agent compatible con Chrome móvil, eliminando marcadores típicos de WebView.
- Soporte para cookies de terceros, JavaScript, almacenamiento DOM y ventanas emergentes.
- Botón ↗ para abrir la página actual en Chrome/navegador del sistema si un sitio bloquea WebView.
- AforeWeb abre por defecto al iniciar la aplicación.
- En AforeWeb, los flujos de cámara usan la cámara real del dispositivo; la fuente virtual queda deshabilitada para procesos de autenticación/identidad.
- Se conserva la página PRUEBA para validar foto/video virtual en sitios de prueba no protegidos.
